# Agentic AI

| Topic | Short Notes |
|-------|-------------|
| **Agentic AI** | AI systems that can plan, reason, use tools, and complete multi-step tasks with minimal human intervention. |
| **AI Agent** | Uses an LLM, memory, planning, and tools/APIs to accomplish goals. |
| **Agent Workflow** | Goal → Plan → Use Tool → Observe Result → Decide Next Step → Complete Task. |
| **Tool Calling (Function Calling)** | LLM invokes APIs or software to perform actions instead of only generating text. |
| **Memory** | Allows agents to remember previous interactions or retrieved information. |
| **Planning** | Agent breaks a complex problem into smaller steps before acting. |
| **Reflection** | Agent evaluates its own output and improves it before responding. |

# Amazon Bedrock

| Topic | Notes |
|--------|-------|
| **Amazon Bedrock** | Fully managed service for building Generative AI applications using foundation models. |
| **Serverless** | No infrastructure management required. |
| **Multiple Foundation Models** | Access Amazon and third-party foundation models through one API. |
| **Knowledge Bases** | Connect enterprise data to foundation models using Retrieval-Augmented Generation (RAG). |
| **Guardrails** | Configure safety policies, content filters, and topic restrictions. |
| **Agents for Bedrock** | Build AI agents capable of planning, tool usage, and autonomous task execution. |
| **Model Evaluation** | Compare foundation model quality before deployment. |

# Amazon PartyRock

| Topic | Notes |
|--------|-------|
| **PartyRock** | No-code AI application builder powered by Amazon Bedrock. |
| **Purpose** | Rapidly prototype AI applications without coding. |
| **Uses** | Chatbots, summarizers, generators, assistants, brainstorming tools. |
| **Widgets** | Drag-and-drop components for prompts and outputs. |
| **Sharing** | Applications can be shared through a public link. |
| **Best For** | Learning prompt engineering and Generative AI concepts. |

# Prompt Engineering (Additional)

| Technique | Purpose |
|----------|---------|
| **Role Prompting** | Assign the model a role (e.g., "You are a financial advisor."). |
| **Delimiters** | Clearly separate instructions from user input using quotes or tags. |
| **Constraints** | Limit output length, style, or format. |
| **Structured Output** | Request JSON, Markdown, tables, or bullet lists. |
| **Iterative Prompting** | Improve prompts through multiple refinements. |

# Foundation Model Selection

Choose a model based on:

- Accuracy
- Cost
- Latency
- Context Window
- Modality (Text, Image, Audio, Video)
- Language Support
- Safety Features

# Important Amazon Bedrock Terms

| Term | Meaning |
|------|---------|
| **Inference** | Sending prompts to a foundation model. |
| **Foundation Model** | Large pretrained AI model adaptable to many tasks. |
| **Prompt** | Input instructions provided to the model. |
| **Completion** | Response generated by the model. |
| **Guardrails** | Safety controls for AI outputs. |
| **Knowledge Base** | External information source used for RAG. |
| **Agent** | AI system capable of planning and using tools. |

# PartyRock vs Amazon Bedrock

| PartyRock | Amazon Bedrock |
|-----------|----------------|
| No-code AI application builder | Managed Generative AI platform |
| Designed for learning and rapid prototyping | Designed for production AI applications |
| Uses Amazon Bedrock underneath | Provides access to foundation models |
